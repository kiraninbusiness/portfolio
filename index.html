THE OFF GRID store

E-commerce UX and front end · Designer and builder · 2026

Problem

An Indian D2C streetwear brand needed a store that builds trust on first visit and makes buying on mobile quick.

What I designed

  • PIN code delivery estimator on the product page, so shoppers see arrival time before the cart.
  • Quick View, color and fit filters, Related Products and Recently Viewed to shorten the path to a size choice.
  • Notify Me waitlist for sold-out sizes instead of a dead end.
  • Returns and exchange flow, gift cards and abandoned-cart recovery.

Research

Benchmarked the flows of Snitch, Nobero, Wrogn and Rare Rabbit before deciding what to keep, drop or simplify.

Result

Built and deployed as an installable web app (React, Node, PostgreSQL), with an admin side that uses two-factor sign-in.
